
# Contributing

Thanks for your interest in Christmas Obby!

Contributions, suggestions and bug reports are welcome. They can help improve the game and make it better for everyone.

## How to Contribute

### Reporting Bugs

If you find a bug, please provide:

- A clear description of the issue.
- The stage where it happened.
- Steps to reproduce the problem.
- Screenshots or videos, if available.

### Suggesting Improvements

You can suggest:

- New stage ideas.
- Gameplay improvements.
- New features.
- Bug fixes.
- Performance improvements.

### Code Contributions

If you want to contribute code:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Submit a Pull Request with a clear description.

## Guidelines

- Keep your changes simple and understandable.
- Test your changes before submitting them.
- Avoid unrelated changes.
- Explain what you changed and why.
- Be respectful when discussing ideas or reviewing contributions.

## Important Notes

Christmas Obby is currently in Beta and is still under development.

Not every suggestion or contribution will necessarily be included in the project.

Thank you for helping improve Christmas Obby!
