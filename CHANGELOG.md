# Changelog

All notable changes to Christmas Obby are documented here.

## [1.0.0] - Final Release

### Added
- Completed the full game with **200 stages**.
- Added a checkpoint system.
- Added a Coins reward system.
- Added a player leaderboard.
- Added persistent player progress saving.
- Added respawning at the latest unlocked checkpoint.
- Added a functional in-game Shop.
- Added purchasable items, including the Speed Coil.
- Added item ownership and persistence across respawns.
- Added custom Shop item icons.

### Development Phases

#### Phase 1 – Stages 1–50
- Created the first 50 obstacle stages.
- Established the basic gameplay mechanics.
- Developed the initial stage progression system.

#### Phase 2 – Stages 51–100
- Expanded the game to 100 stages.
- Added more obstacle variations.
- Improved stage design and gameplay progression.

#### Phase 3 – Stages 101–150
- Expanded the game to 150 stages.
- Introduced additional obstacle challenges.
- Continued improving the overall level design.

#### Phase 4 – Stages 151–200
- Completed the final 50 stages.
- Reached the total of 200 stages.
- Reviewed stage progression and checkpoint placement.
- Completed the main obstacle course.

### Visual Improvements
- Improved the overall visual style of the game.
- Redesigned the Lobby with a stronger Christmas theme.
- Added Christmas decorations and festive details.
- Improved the visual presentation of the stages.
- Designed a new Christmas-themed game Thumbnail.
- Created a new game Icon.

### Systems & Improvements
- Improved the Stages and Coins saving system.
- Improved checkpoint progression and respawning.
- Improved Shop functionality and item persistence.
- Fixed issues discovered during development and testing.
- Optimized gameplay systems and overall stability.

### Testing & Quality Assurance
- Tested all 200 stages and checkpoint progression.
- Tested Coins rewards and leaderboard updates.
- Tested player data saving and loading.
- Tested Shop purchases and item functionality.
- Performed repeated tests of the Stages and Coins saving system.
- Tested gameplay on different types of devices.
- Checked gameplay functionality and interface compatibility across different device types.
- Conducted final gameplay and stability checks.

### Final Release Notes
- Christmas Obby has reached its final release.
- The game is no longer presented as a Beta version.
- All 200 stages are included in the final release.
- Core gameplay systems have been implemented and tested.
- The final version is available for players.
