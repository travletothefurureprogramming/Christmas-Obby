
# Changelog

All notable changes to Christmas Obby are documented here.

## [Unreleased]

- Further improvements to the stages.
- Bug fixes and gameplay improvements.

## [Beta]

### Added
- Expanded the game to 170 stages.
- Added a checkpoint system.
- Added a Coins system.
- Added a player leaderboard.
- Added progress saving.
- Added respawning at the latest unlocked checkpoint.

### Notes
- The game is still under development.
- Player progress, Stages or Coins may be reset during testing or future updates.
