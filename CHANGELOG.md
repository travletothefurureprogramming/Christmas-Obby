# Changelog

All notable changes to Christmas Obby are documented here.

## [Unreleased]

- Further improvements to stages and gameplay.
- Additional bug fixes and system optimizations.
- Performance improvements and final testing.
- Further visual and interface improvements.

## [Beta]

### Added
- Expanded the game to **200 stages**.
- Added a checkpoint system.
- Added a Coins reward system.
- Added a player leaderboard.
- Added player progress saving.
- Added respawning at the latest unlocked checkpoint.
- Added a functional in-game Shop.
- Added purchasable items, including the Speed Coil.
- Added item ownership and persistence across respawns.
- Added custom Shop item icons.

### Changed
- Improved the overall visual style of the game.
- Redesigned the Lobby with a stronger Christmas theme.
- Added more Christmas decorations and festive details.
- Improved the game's visual presentation.
- Designed a new Christmas-themed game Thumbnail.
- Created a new game Icon.
- Improved the Stages and Coins saving system.

### Testing & Improvements
- Tested all 200 stages and checkpoint progression.
- Tested Coins rewards and leaderboard updates.
- Tested player data saving and loading.
- Tested Shop purchases and item functionality.
- Conducted repeated testing of the new Stages and Coins saving system.
- Reviewed gameplay stability and identified potential issues.

### Notes
- The game is still under development.
- Some features and systems may receive further changes.
- Player progress, Stages or Coins may be reset during testing or future updates.
- The new saving system is undergoing additional verification.
- Thumbnail and Icon updates may take time to appear on Roblox.
