
# Development

## About the Project

Christmas Obby is a Christmas-themed obstacle course game developed using Roblox Studio.

The project focuses on creating stages, adding gameplay systems and improving the overall player experience.

## Current Progress

The game currently has 170 stages.

The following systems have been implemented:

- Stage progression
- Checkpoints
- Coins
- Player leaderboard
- Data saving
- Respawning at the latest unlocked checkpoint

## Development Process

Development is divided into a few main areas:

### Stage Design

Creating new obstacles and stages while keeping the difficulty balanced and the gameplay interesting.

### Gameplay Systems

Working on checkpoints, Coins, leaderboards and player progression.

### Testing

Testing the game to find bugs and checking that the systems work as expected.

### Improvements

Making changes based on testing and improving the overall gameplay experience.

## Current Priorities

- Test the progress saving system.
- Check checkpoint and respawn behaviour.
- Fix bugs found during testing.
- Improve existing stages.
- Continue developing the game.

## Project Status

Christmas Obby is currently in Beta.

Some features may change during development. Player progress and Coins may be reset during testing or future updates.
