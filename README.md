
# Christmas Obby

(Thumbail)[images/CHRISTMAS OBBY.png]

Christmas Obby is a Christmas-themed obstacle course game on Roblox. The goal is to complete the stages, reach checkpoints and collect Coins along the way.

## Game Information

- Platform: Roblox
- Genre: Obby
- Status: Beta
- Stages: 200
- Game link: [Play Christmas Obby](https://www.roblox.com/games/91579596930314/Christmas-Obby-Progress-May-Be-Lost)

## Features

- 200 stages to complete
- Checkpoint system
- Coins system
- Player leaderboard
- Progress saving
- Respawning at the latest unlocked checkpoint

## How to Play

1. Join the game using the Roblox link.
2. Complete the obstacles to move to the next stages.
3. Reach checkpoints to track your progress.
4. Collect Coins while playing.
5. Try to complete all 200 stages.

## Beta Notice

The game is still under development, so you may encounter bugs or unexpected issues.

Your Stages, Coins or saved progress may be reset or lost during testing or future updates.

Thanks for playing and helping me improve the game!

## Development

Christmas Obby is developed using Roblox Studio. I am still working on improving the stages, fixing bugs and making the gameplay better.
